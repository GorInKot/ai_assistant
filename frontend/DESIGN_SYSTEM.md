# Дизайн-система ассистента

Корпоративные цвета: чёрный, графит, золотисто-жёлтый. Базовые значения совпадают с темой
корпоративного портала: ассистент открывается его разделом и не должен выглядеть чужим.

## Где что лежит

| Файл | Что в нём |
|---|---|
| `src/styles/tokens.css` | токены в три слоя: базовые значения → смысловые роли → компоненты |
| `tailwind.config.js` | классы Tailwind по смысловым ролям (`bg-surface`, `text-ink-muted`, `bg-primary`…) |
| `src/index.css` | компонентные классы: `btn-primary`, `btn-soft`, `sidebar-rule`, `sidebar-item-active`, `avatar-*` |

Правило: в коде интерфейса — только роли и компонентные классы, ни одного цвета напрямую.
Сменить брендбук — поменять базовый слой в `tokens.css`. Проверка:
`node <skill>/scripts/validate-tokens.cjs --dir src/`.

## Палитра

| Роль | Класс | Значение | Где |
|---|---|---|---|
| Главное действие | `bg-primary` + `text-primary-fg` | #e8a419 / #0b0d10 | кнопки, аватар ассистента |
| Акцентный текст | `text-primary-strong` | #8a5a06 | ссылки, «открыть / скачать» |
| Тёмная зона | `bg-inverse`, `text-inverse-fg` | #151920 / #f2f3f5 | боковая панель |
| Фон | `bg-canvas`, `bg-surface-muted` | #f2f3f5, #f8f9fb | страница, лента чата |
| Поверхность | `bg-surface`, `border-line` | #ffffff, #e3e6eb | карточки, окна |
| Текст | `text-ink` → `-soft` → `-muted` → `-subtle` | #171a1f … #646b76 | по важности |
| Состояния | `success`, `warning`, `danger`, `info` (`-soft`, `-line`) | | проверка опоры, «проверить», ошибки |

Контраст: текст на золоте только тёмный (9,6:1; белый — 2,1:1, не годится); самый светлый
текст для чтения `text-ink-subtle` — 4,8:1 на фоне страницы; `text-ink-faint` — только иконки
и неактивное.

## Типографика и форма

- Текст — Roboto, заголовки страниц — Roboto Condensed прописными (как в портале); без
  установленных шрифтов — Arial / Arial Narrow.
- Углы строже, чем по умолчанию в Tailwind: `rounded-lg` = 4px, `rounded-xl` = 6px.
- Фирменный приём портала — золотая черта: под шапкой боковой панели и слева у активной беседы.

## Компоненты

| Класс | Обычное | Наведение | Фокус | Неактивное |
|---|---|---|---|---|
| `btn-primary` | золото, тёмный текст | темнее золото | золотая рамка 2px | `disabled:opacity-*` |
| `btn-soft` | светлое золото, тёмно-золотой текст, рамка | насыщеннее фон | золотая рамка 2px | `disabled:opacity-*` |
| `sidebar-item-active` | графит + золотая полоса слева | — | — | — |
