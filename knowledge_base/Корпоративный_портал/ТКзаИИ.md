# Раздел «ТКзаИИ»: технический контроль за инженерными изысканиями

## Назначение
Раздел (адрес /tkzaii/) ведёт реестр проверок документации по инженерным изысканиям (ИИ): что поступило, кто проверяет, регламентный срок, когда выдано заключение и с каким результатом. Страницы: «Реестр ТКзаИИ», «Дашборд ТКзаИИ», «Словари», «Журнал действий» (руководители и администраторы), «Нормативы» (администраторы), импорт и экспорт Excel.

## Реестр ТКзаИИ
Таблица позиций (одна позиция — один поступивший документ на проверку). Столбцы можно выбрать: кнопка «Столбцы таблицы» → отметить нужные («Отметить все», «Снять все», «Показать все») → «Применить». Настройка сохраняется для вашей учётной записи; по умолчанию показываются все столбцы. Столбцы сортируются щелчком по заголовку (стрелка «⇅»).

Фильтры: «Все филиалы», «Все виды документа», «Все виды ИИ», «Любая сложность», «Любой статус», «Специалист», даты поступления «с» и «по», поиск по теме, объекту, заказчику, исполнителю, договору, шифру. «Найти» применяет, «Сбросить» снимает фильтры.

Кнопки: «+ Добавить позицию», «Импорт из Excel», «Экспорт в Excel». В строке: «Изменить», «Создать на основе» (копия позиции), «+ Итерация» (повторная проверка того же документа), «Удалить». Добавление, изменение, удаление и импорт требуют права редактирования.

## Поля позиции
Вх. № письма, Тема вх. письма, Дата поступления, Филиал, № Договора, Заказчик, КНИПИ, Исполнитель, Шифр, Наименование объекта, Приоритетность объекта, Вид документа, № доп/изм, Итерации, Вид ИИ, Сложность, Специалист, Дата начала проверки, Регламентная дата, Дата выдачи заключения, Статус, Трудозатраты (чел.час.), Организация отправитель, Исх. № письма, Исх. № письма дата, № АВР, Примечание.

Значения справочников:
- Вид документа: ТЗ, доп к ТЗ, ППР, ТО, лаборатор, ОТГ, Поле, ИС, ДК.
- Вид ИИ: ИГДИ (инженерно-геодезические), ИГИ (инженерно-геологические), ИГМИ (инженерно-гидрометеорологические), ИЭИ (инженерно-экологические), ИГФИ (инженерно-геофизические изыскания).
- Сложность: несложный, сложный, уникальный.
- Статус (результат проверки): положительное, отрицательное.

## Этапы позиции
Этап определяется по заполненным полям:
- «нераспределённые» — специалист не назначен;
- «в очереди» — специалист назначен, проверка не начата (нет даты начала проверки);
- «на проверке» — есть дата начала проверки, нет даты выдачи заключения;
- «выдано» — есть дата выдачи заключения; результат — статус «положительное» или «отрицательное».

Тип проверки: первая итерация — «первичная», вторая и далее — «повторная».

## Регламентная дата и трудозатраты
Регламентная дата и трудозатраты подставляются по нормативу для сочетания «вид документа + тип проверки (первичная/повторная) + сложность». Регламентная дата = дата начала проверки + число рабочих дней из норматива; выходные и нерабочие праздничные дни пропускаются. Просрочка = дата выдачи заключения − регламентная дата (в днях). Нормативы (регламент в днях, трудозатраты в часах) и нерабочие дни ведёт администратор на странице «Нормативы».

## Словари
Для повторяющихся значений — Заказчик, КНИПИ, Исполнитель, Организация отправитель, Приоритетность объекта, № Договора — ведутся словари: в форме позиции они подсказывают значения. На странице «Словари» значения можно добавить, переименовать, удалить и найти.

## Дашборд ТКзаИИ
Фильтры: период по дате поступления (по умолчанию последние 8 недель), «Все филиалы», «Все виды ИИ»; «Применить», «Сбросить». Блоки:
- «Сводка по филиалам»;
- «Проверено по неделям»;
- «Филиал × Вид ИИ — текущая загрузка по неделям периода»;
- «Загрузка специалистов (по документам, поступившим в диапазоне дат)»;
- «Рейтинг специалистов по кол-ву документов (за период)»;
- «Просрочка среди открытых позиций (сегодня − дата поступления)».

## Импорт, экспорт и журнал
- Импорт из Excel перед загрузкой сохраняет резервную копию; итог импорта записывается в журнал.
- «Экспорт в Excel» — выгрузка реестра с выбранными фильтрами.
- «Журнал действий» (руководители и администраторы): кто, когда и что изменил (добавление, изменение, удаление, импорт); действие можно отменить.
