# Раздел «СИЗ»: учёт средств индивидуальной защиты

## Назначение
Раздел «СИЗ-РНСК» (адрес /siz/) — учёт, анализ и выгрузки по средствам индивидуальной защиты (СИЗ): кто из работников какие СИЗ получил, когда истекает срок носки, какова оснащённость по нормам и потребность в закупке. Вкладки вверху: «БАЗА», «МБ7», «СИОС», «Дашборды», «Оснащенность», «Склад», «Без НГ» и «⚙» (настройки). Таблицы раздела — интерактивные: у каждой колонки есть строка фильтра, колонки можно сортировать.

## Вкладка «БАЗА»
- «Горизонт истечения срока»: 1 мес, 2 мес, 3 мес, Пол года, Год — за какой срок вперёд считать СИЗ «истекающими».
- «Экспорт Excel».
- «Личные карточки»: «Скачать карточку выбранного работника», «Скачать карточки открытых работников ZIP».
- «Листы комплектации»: «Скачать лист выбранного работника», «Скачать листы открытых работников ZIP».
- «Фильтр значений»: Филиал, ПУ, Работник, Должность, Категория СИЗ; кнопки «Все», «Снять», «Применить», «Сбросить все».
- Показатели: «Работников», «Всего СИЗ», «Истекает», «Ближайших дат».
- Таблица «Работники»: ФИО, Филиал, ПУ, Подразделение, Должность, Категории СИЗ, МБ7, СИЗ МБ7, СИЗ, Истекает.
- Таблица «СИЗ выбранного работника»: СИЗ, Категория, Размер/рост, Кол-во, Норма выдачи, Примененное правило, Дата выдачи, Срок носки, Дата списания. Работника выбирают щелчком по строке в таблице «Работники».

## Вкладка «Оснащенность»
Оснащённость работников СИЗ по нормам.
- «Отчёт»: «На год» или «На текущий месяц»; флажок «Учитывать сотрудников в отпуске».
- Расчёт на год: Норма (год) = норма выдачи × 12 / срок носки; Оснащённость = выдано / норма (год) × 100 %.
- Расчёт на текущий месяц: норма = округление вверх (норма выдачи / срок носки) на работника, затем суммируется по работникам ПУ; Потребность = округление вверх (max(норма − факт, 0)).
- «Категории» — фильтр категорий СИЗ.
- «Трудоустроено всего» и по филиалам.
- «График оснащенности по номенклатурным группам» (НГ): текущий месяц или год, норма и факт; «XLS» — выгрузка.
- «Уровень»: Общество, Филиал, ПУ; «Фильтр НГ».
- Показатели: Факт, Норма, Потребность, Оснащенность (%).
- Таблицы «Филиалы» и «ПУ и СИЗ выбранного филиала»; «Аномалии: превышение нормы выдачи» — где выдано больше нормы.

## Вкладка «Дашборды»
- Горизонт (1 мес … Год), уровень (Общество, Филиал, ПУ, Работник), фильтр категорий.
- Показатели: Групп, Работников, СИЗ, Истекает.
- «Структура по выбранному уровню»: СИЗ, Работники, Истекает, Норма, Выдано; Топ 8 / 12 / 20.
- «План закупок по месяцам по датам списания»: только по ПУ, с ФИО или пофамильно списком; «XLS», «Выгрузить таблицу», «Проверить наличие на складе».
- «Статистика по выбранному уровню», «Карточка», «Выгрузить потребность по ПУ», «График помесячной оснащенности».

## Вкладка «МБ7»
Формы МБ-7 (ведомость учёта выдачи спецодежды, спецобуви и предохранительных приспособлений).
- «Загруженные формы МБ7»: «Загрузить», «Шаблон», «Выгрузить форму», «Удалить форму»; статусы формы — «На регистрации» и «Зарегистрировано».
- «Записи» формы: «Добавить», «Редактировать», «Удалить», «Удалить все».

## Вкладка «СИОС»
Записи СИОС: «Выдать», «Редактировать», «Загрузить» (с флажком «Заменить текущие записи»), «Шаблон», «Выгрузить записи», «Удалить выбранные», «Удалить все». Таблица — «Записи СИОС».

## Вкладка «Склад»
«Склад по счету 10.10» — остатки по данным оборотно-сальдовой ведомости 1С; «Обновить»; «Маски размеров» и «Актуализировать размеры» — как из наименования материала определяется размер.

## Вкладка «Без НГ»
Материалы без номенклатурной группы (НГ): «1. Выберите материал без НГ», затем «Добавить в существующую НГ» или «Создать новую НГ» и «Сохранить НГ для материала». Таблицы «Отбракованные материалы без номенклатурной группы» и «Записи выбранного материала». Блок «Расчёт потребности и показ в оснащённости по НГ»: для отмеченных НГ можно отключить расчёт потребности на будущие периоды (выданные позиции дохаживают срок носки) и снять их по умолчанию с показа в оснащённости; кнопки «Добавить», «Сохранить».

## Вкладка «⚙» (настройки и загрузка данных)
- «Проверить БД», «Создать/обновить структуру БД», «Стартовый пакет», «Резервная выгрузка».
- «Загрузка данных»: «Файл 1С» → «Загрузить и обработать 1С»; «Правила загрузки» → «Применить правила»; «Работники XML» → «Обновить работников из XML»; «ОСВ 10.10» → «Загрузить склад».
- Для склада нужен файл из 1С — «Оборотно-сальдовая ведомость по счёту 10.10» с группировкой Подразделение → МОЛ → Номенклатура (строки «БУ»/«Кол.» под каждым ФИО). Вручную отредактированный или собранный файл может распознаться неверно.
- После загрузки работников из XML строки подсвечиваются: новые, изменены, уволены, удалены, пропущены.
- «Быстрое управление загрузкой работников»: флажок «Загружать» у подразделения означает, что его работники из XML учитываются при обновлении; кнопки «Загружать выбранные», «Не загружать выбранные», «Загружать все отфильтрованные», «Не загружать все отфильтрованные».
- «Таблицы БД»: «Добавить строку», «Редактировать строку», «Удалить выбранную»; «Экспорт», «Актуализация», «Замена данных».
- «Логи работы с БД» → «Обновить логи».

## Права
Открыть раздел и смотреть данные можно с правом просмотра раздела «СИЗ». Изменения данных (загрузки, выдача, редактирование, удаление) требуют права редактирования; без него портал отвечает «У вашей роли недостаточно прав для редактирования данных СИЗ». Действия подписываются в журнале фамилией и инициалами вошедшего пользователя.
