# Раздел «Панель задач»

В демонстрационной надстройке портала раздел «Панель задач» (адрес /tasks/) показывает пункты существующего раздела «Протокол» по группам «В работе», «Требуют внимания» и «Исполнено». Карточка содержит поручение, ответственного, срок, ссылку на пункт протокола и, для пунктов из записи IVA, исходную реплику со временем и ссылкой на запись. Изменения вносятся в «Протоколе», отдельной копии задач нет. Для просмотра нужны права на «Панель задач» и «Протокол».

В портале без демонстрационной надстройки раздел по-прежнему показывает страницу «В разработке».
