# Раздел «Метрики»: дашборды подразделений

## Назначение
Раздел (адрес /metrics/) открывает сводные HTML-дашборды и показатели подразделений. Стартовая страница раздела — «Дашборды основные»; с неё открываются дашборды по направлениям (например, кадры, МТО, ПБОТОС, экономисты и другие).

## Работа с дашбордами
Дашборды открываются внутри портала; данные для них загружаются с портала. Если в дашборде есть журнал изменений, записи подписываются фамилией и инициалами вошедшего пользователя.

## Права
Раздел виден и открывается с правом просмотра раздела «Метрики».
