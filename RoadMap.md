# План-роадмап: работа с документами

**Дата составления:** 2026-06-15
**Контекст:** Этап 5 роадмапа закрыт (см. [RoadMap05.md](RoadMap05.md)). Новое направление — обработка пользовательских документов внутри ассистента.

**Конечная цель:** пользователь загружает в чат файл (Excel/Word), а ассистент умеет извлекать из него данные, обрабатывать (выжимка, объединение, сравнение) и возвращать результат.

---

## Этап 6. Работа с документами

### 6.A. Excel (`.xlsx`/`.xls`)

| # | Возможность | Описание |
|---|---|---|
| 6.A.1 | Извлечение данных | Разобрать загруженный файл: листы, таблицы, заголовки, строки. Вернуть структурированное представление. |
| 6.A.2 | Объединение нескольких файлов | Слить несколько небольших файлов в один. **Предусловие:** проверка идентичности структуры таблиц (совпадение набора/порядка/типов колонок). При расхождении — сообщить пользователю, что именно не совпало, и не объединять «вслепую». |
| 6.A.3 | Поиск различий | Сравнить два (или более) файла и показать различия: добавленные/удалённые строки, изменённые ячейки, расхождения в структуре. |

### 6.B. Word (`.docx`)

| # | Возможность | Описание |
|---|---|---|
| 6.B.1 | Извлечение данных | Разобрать загруженный файл: текст, заголовки, абзацы, таблицы внутри документа. |
| 6.B.2 | Краткая выжимка | По большому тексту вернуть краткое резюме (summary) через LLM. |
| 6.B.3 | Сравнение файлов | Сравнить два файла одного типа и найти различия (изменения в тексте, добавленные/удалённые фрагменты). |

## Открытые вопросы (уточнить перед реализацией)

1. **Загрузка файлов.** Через чат (вложение к сообщению) или отдельная ручка/UI? Где хранить загруженный файл — временно на время сессии или в БД?
2. **Лимиты.** Максимальный размер файла, число строк/листов, число одновременно объединяемых/сравниваемых файлов.
3. **Формат вывода различий.** Текстовый отчёт в чате, скачиваемый файл (diff/новый xlsx), или и то и другое?
4. **Excel-объединение «идентичная структура».** Насколько строгая проверка: только имена колонок, или ещё порядок и типы? Что делать с разным регистром/пробелами в заголовках?
5. **Word-сравнение.** Diff по словам/предложениям/абзацам? Учитывать ли форматирование или только текст?
6. **Выжимка Word.** Длина резюме, язык, использовать ли существующий LLM-конфиг (Groq/YC).

## Этап 7. Автозаполнение шаблонов заявок на доступ к системам

**Цель:** пользователь произвольным текстом передаёт свои данные, ассистент сам понимает, какие данные для чего нужны, заполняет шаблон заявки и выдаёт пользователю готовый заполненный документ.

> **Источник механики:** пользователь предоставил рабочие VBA-макросы автозаполнения (`VBA/*.txt`) для 4 систем — **Лаборатория ИИ, ЦУС, Терминальный сервер, ВКД**. По ним воспроизводим логику в ассистенте.

### Прогресс

| Система | Статус | Способ |
|---|---|---|
| **Лаборатория ИИ** | ✅ готово (2026-06-19) | заполнение готового шаблона `.xlsx` |
| ЦУС | ⏳ запланировано | строится с нуля кодом |
| Терминальный сервер | ⏳ запланировано | строится с нуля кодом |
| ВКД | ⏳ запланировано | строится с нуля кодом |

### Сделано: Лаборатория ИИ (✅)

**Что получили:** пользователь в чате свободным текстом описывает данные (сотрудник, руководитель, подразделение, ключ ПКЗИ) и просит «оформи/заполни заявку на Лабораторию ИИ». Ассистент распознаёт намерение, через LLM извлекает поля, заполняет бланк `Шаблон_Лаборатория.xlsx` и отдаёт готовый `Заявка_<ФИО>.xlsx` на скачивание. Если обязательных данных не хватает — не выдумывает, а перечисляет недостающее и просит дописать.

**Решённые развилки (договорённости с пользователем):**
- **Ввод** — свободный текст в чате (а не загрузка «Базы» Excel, как в макросе).
- **Шаблон Лаборатории** — предоставлен пользователем (`Шаблон_Лаборатория.xlsx`), хранится в `app/form_templates/lab_ai.xlsx`.
- **Маппинг полей** — по макросу `LaboratoryAI_3_1`: подразделение → F15/H47; «ФИО, должность, телефон» работника → F16; то же по руководителю → F17; ключ ПКЗИ → F18; дата (текущая, период «по» = год+1) → F31/H31/I31/K31/M31/N31; ФИО внизу → B43 (работник)/B50 (руководитель).
- **Выдача** — готовый файл + текстовая сводка распознанных полей в чате.
- **Объём** — пока один сотрудник за запрос (многих — позже).

**Технические заметки / грабли:**
- Детект интента консервативный: нужен И глагол («оформи/заполни/сформируй/…»), И название системы — иначе обычные вопросы про лабораторию не перехватываются. Встроено в `/api/ask` шагом 0, не мешает заявкам Этапа 5 и QA.
- Файлы обрабатываются в памяти, на сервере не сохраняются (как в Этапе 6).
- **Совместимость с Apple Numbers:** openpyxl при `load+save` пересобирает пакет в свой диалект (теряет `printerSettings`, `worksheets/_rels`, пишет inline-строки вместо `sharedStrings`). Excel/Google Sheets открывают, **Numbers — нет**. Решение: патчим исходный Excel-пакет напрямую (меняем только нужные ячейки и `sharedStrings`, остальное байт-в-байт). Подтверждено пользователем — открывается в Numbers.
- **Скачивание на фронте:** перевели вложения на Blob/object-URL вместо `data:`-URI (для бинарных `.xlsx` data-URI повреждал байты). Заодно чинит скачивание `merged.xlsx` из Этапа 6.

**Файлы:** `app/services/request_forms.py` (реестр систем, детект, заполнение, патч пакета), `app/llm.py::extract_fields`, `app/services/ask_service.py` (шаг 0), `app/form_templates/lab_ai.xlsx`, `frontend/src/chat/MessageList.tsx` (Blob-скачивание), `tests/test_request_forms.py` (10 тестов).
