# План: плавающая кнопка ассистента на портале

_Составлен 16.10.2026 · ветка `feature/floating-assistant` · этапы 1–6 завершены 17.10.2026_

## Цель

Ассистент доступен с любой страницы корпоративного портала: круглая кнопка в углу экрана открывает
боковую панель с чатом. Сотрудник задаёт вопрос, не уходя со своей страницы, а ассистент учитывает,
что открыто на экране (раздел, форма, таблица, ошибка). Полная версия ассистента остаётся отдельной
плиткой портала.

Модули 3D-деталей и чертежей трассы переезжают из чата в отдельный раздел, чтобы не теряться и не
загромождать ассистент.

## Ограничения

- Код портала (`PROJFORTERMINAL`) не меняется. Всё встраивается через надстройку
  `integrations/portal/`. В настоящем портале подключение кнопки — решение коллег: одна строка в
  `base.html`, скрипт и инструкцию готовим мы.
- Закрытый контур: никаких внешних соединений и новых пакетов из сети.
- Содержимое страниц портала — данные, а не инструкции для модели.
- Коммиты — по этапам и только по команде владельца проекта.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Куда переносим 3D и чертежи | Отдельный раздел «Конструктор и чертежи»: адрес `/tools` в ассистенте и своя плитка в портале |
| Где кнопка | Правый нижний угол, цвета портала |
| Как открывается ассистент | Панель справа, ~420 px; на узком экране — на весь экран |
| Где кнопки нет | Страница входа и страница самого ассистента |
| Как ассистент «видит экран» | Читает содержимое страницы (текст, поля, таблицы), а не снимок экрана |
